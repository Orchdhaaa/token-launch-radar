How the radar ranks

  1. Universe. All 758 protocols in the sealed snapshot. The board keeps the ones that record no token and are not a wrapped, staked or bridged product of a token that already trades — the snapshot’s own watchlist rule, applied to the whole file instead of only above the $50M floor. That finds 198 launch candidates, the 40 watchlist protocols included.
  2. Implied value. TVL × the traded median market-cap / TVL multiple × a growth factor from the 7-day TVL change × an age factor for how long the protocol has run with no token recorded × a breadth factor for how many chains it runs on. No protocol name is hardcoded anywhere in the model.
  3. Farm plan. Every row carries six concrete steps — what to do, what it costs, how long it takes — built from the protocol’s own category, chains and size.
  4. What this is not. The board does not predict whether or when any protocol issues a token. It prices the launch if the protocol’s record stayed as it is.
